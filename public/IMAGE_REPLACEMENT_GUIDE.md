# Image replacement guide

The code expects these exact image paths.

## Main website images

Place in `public/`:

- `hero-landfill.jpg` — real landfill / mixed plastic waste hero image
- `plastic-bales.jpg` — real plastic bales / MRF / feedstock image
- `clean-reactor.jpg` — real reactor / industrial process / pilot plant image
- `intelligence-ml.jpg` — real control room / dashboard / industrial monitoring image
- `ship-marine.jpg` — real ship / port / marine fuel image
- `heavy-industry.jpg` — real factory / boiler / cement / heavy industry image
- `circular-economy.jpg` — real circularity / recovered material / clean industrial image
- `impact-plant.jpg` — real industrial plant image
- `impact-workers.jpg` — real waste recovery / material handling workers image
- `impact-community.jpg` — real waste logistics or community/material recovery image
- `carbonm-logo.png` — CarbonM logo
